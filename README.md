# Погода.Юг

Многостраничный сайт с прогнозом погоды для городов Краснодарского края. Оформление страницы и плейлист подстраиваются под текущую погоду.

**Демо:** [ссылка на GitHub Pages]

## Возможности
- Текущая температура, описание погоды и атмосферное давление (мм рт. ст.)
- Выбор из 9 городов: Краснодар, Сочи, Геленджик, Ейск, Приморско-Ахтарск и другие
- Почасовой прогноз на ближайшие 9 часов и прогноз на 7 дней
- Тема оформления меняется в зависимости от погоды (ясно, облачно, дождь, снег, гроза)
- «Плейлист дня»: подборка из Яндекс Музыки выбирается по погоде и температуре
- Выбранный город запоминается в браузере (localStorage)
- Адаптивное бургер-меню с подсветкой текущей страницы

## Страницы
| Страница | Назначение |
|---|---|
| `index.html` | Главная: текущая погода |
| `today.html` | Погода на сегодня по часам |
| `week.html` | Прогноз на неделю |
| `song.html` | Плейлист дня |

## Технологии
- HTML5, CSS3
- JavaScript (ES6+, `fetch`, `async/await`, работа с DOM, localStorage)
- [Open-Meteo API](https://open-meteo.com/): бесплатный API погоды, ключ не нужен
- Google Fonts (Poppins)
- Яндекс Музыка (встраиваемые плейлисты)
- Публикация: GitHub Pages

## Как это работает
Скрипт `script.js` запрашивает данные у Open-Meteo по координатам выбранного города, переводит код погоды в описание, иконку и тему оформления, затем заполняет страницу. Один и тот же скрипт подключён ко всем страницам и обновляет только те элементы, которые на них есть.

## Запуск
Открыть `index.html` в браузере. Для загрузки данных о погоде нужен интернет.
